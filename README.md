# KiCad Custom Footprint Libraries, Symbols and 3D Models

Custom footprints, symbol libraries and 3D models used by the activity5 LoRa
sensor board (ESP32-S3 + BQ24074 charger + XC6220 LDO + RA-01SH LoRa + BME280 + GPS + SD/USB-C).

Exported from KiCad 10 / easyeda2kicad on 2026-11-13.

## Install on another PC

Clone or download this repository, then run the installer for your OS.
Close KiCad first so it cannot overwrite `fp-lib-table` on exit.

### Windows (PowerShell)

```powershell
.\install.ps1
```

Optional parameters:

```powershell
.\install.ps1 -KicadVersion 10.0 -InstallDir "D:\KiCadLibs" -ConfigDir "C:\Users\me\AppData\Roaming\kicad\10.0"
```

### Linux / macOS

```bash
chmod +x install.sh
./install.sh
```

Optional environment variables:

```bash
KICAD_VERSION=10.0 INSTALL_DIR="$HOME/kicad-libs" CONFIG_DIR="$HOME/.config/kicad/10.0" ./install.sh
```

### What the installer does

1. Copies all `.pretty` folders, `.kicad_sym` files and `.3dshapes` folders to
   the install folder (default: `Documents/KiCad/<version>/kicad-custom-libs`).
2. Rewrites every 3D model path inside the installed footprints to an absolute
   path under the install folder, so no environment variables are required
   on the target machine.
3. Adds or updates the nine footprint libraries in `fp-lib-table` and the
   nine symbol libraries in `sym-lib-table`.

Restart KiCad afterwards and check Preferences -> Manage Footprint Libraries
and Preferences -> Manage Symbol Libraries.

## Using these libraries manually

Register each `.pretty` folder as a KiCad footprint library
(Preferences -> Manage Footprint Libraries), for example:

```
(lib (name "easyeda2kicad") (type "KiCad") (uri "${KICAD_CUSTOM_LIBS}/footprints/easyeda2kicad.pretty"))
(lib (name "SK-3296S-01-L2") (type "KiCad") (uri "${KICAD_CUSTOM_LIBS}/footprints/SK-3296S-01-L2.pretty"))
```

Register each `symbols/*.kicad_sym` file as a symbol library
(Preferences -> Manage Symbol Libraries), for example:

```
(lib (name "easyeda2kicad") (type "KiCad") (uri "${KICAD_CUSTOM_LIBS}/symbols/easyeda2kicad.kicad_sym"))
(lib (name "SK-3296S-01-L2") (type "KiCad") (uri "${KICAD_CUSTOM_LIBS}/symbols/SK-3296S-01-L2.kicad_sym"))
(lib (name "Kicad-Lora") (type "KiCad") (uri "${KICAD_CUSTOM_LIBS}/symbols/Kicad-Lora.kicad_sym"))
```

Set `KICAD_CUSTOM_LIBS` to the folder where this repo is cloned, or use absolute paths.

## 3D model paths

- `easyeda2kicad` footprints reference `${EASYEDA2KICAD}/easyeda2kicad.3dshapes/<part>.wrl`.
  Set the `EASYEDA2KICAD` environment variable to the folder containing
  `easyeda2kicad.3dshapes` (KiCad supports this under
  Preferences -> Configure Paths).
- `SK-3296S-01-L2`, `TYPEC-304J-BCP16`, `Ziisor_IPEX-1`, `IPEX-1`,
  `PinHeader_2P` and `JST_PH_2P` footprints contain absolute model paths such as
  `C:/Users/Vvirtue/Documents/KiCad/10.0/3dmodels/<lib>.3dshapes/<model>.step`.
  On another machine either place the `.3dshapes` folders there, or edit the
  model path in the footprint properties.
- `Project_Components` footprints reference
  `C:/Users/Vvirtue/AppData/Local/KiCadComponentImporter/global_libraries/3DModels/Project_Components.3dshapes/...`
  (generated by KiCadComponentImporter).
- `new_footprint` models were copied from `Pictures/Import/3d`; some references
  are relative (`ZMPT101B.stp`) and some absolute.

The installers above rewrite all of these paths to the local install folder
automatically; the list below describes the raw files in this repository.

Both `.wrl` and `.step` versions are included where available. The footprints
reference `.wrl` for the KiCad 3D viewer; switch the reference to `.step` if you
need STEP export.
